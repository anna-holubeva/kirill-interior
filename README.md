# Лендинг «Опрос + 3 гайда» — вёрстка v1 (22.07.2026)

Конверсионный лендинг под воронку: посетитель проходит короткий опрос → получает один из 3 PDF-гайдов в Телеграм-бот.

**Файлы:** `index.html` (одностраничник) · `fonts/` (локальные Manrope + Unbounded + Prata) · `img/` (фото Кирилла + 3 обложки гайдов для веера в hero).
Текст — из `../лендинг-опрос-v2.md` (без переписывания, только вёрстка).

## Дизайн-система
Один стиль с гайдами (`../гайд1-дизайн`, `2`, `3`): палитра blackandhoney.ru — терракотовый герой `#E85D3C`, медовый акцент `#FFC857`, тёплая бумага `#F7F5F2`, пастельные жёлтый/фиолетовый/зелёный (кодируют 3 гайда), тёмные плашки-якоря `#171513`. Шрифты: **Manrope** (текст), **Unbounded** (цифры/лейблы), **Prata** (serif-акцент в заголовках). Кикеры с линией, пилюли, ✓-списки, финальная лента выкрасов — всё как в гайдах.

## Структура (7 экранов)
1. **Хедер** — sticky, при скролле светлеет, CTA «Пройти опрос».
2. **Hero** — терра-блок: крупный H1 «Ремонт без дизайнера» (первое и главное) → медовый подзаголовок Manrope «Как не слить бюджет…» → описание → CTA «Пройти опрос и забрать гайд» + trust-строка (8 мин / PDF / бесплатно) + **кредл-плашка «Гайды готовит команда практикующих дизайнеров Black & Honey»** (иконка людей). Справа — **3 CSS-3D-книги** с настоящими обложками гайдов (веером, средняя приподнята; толщина страниц + корешок + тень; вписаны в терракотовый фон, медовое сияние-подложка) + бейдж «3 гайда в подарок». Хедер-CTA — «Получить гайд».
3. **Боль** — «Почему ремонт стоит дороже» + 3 карточки (планировка/цвет/бригада) + тёмная плашка «200 000 ₽».
4. **Гайды** — 3 пастельные карточки. У каждой сверху — **крупная 3D-книга** (тот же компонент `.book`, что в героине) с обложкой гайда на пастельном радиальном фоне под цвет карточки, плашка «PDF-гайд в подарок». Ниже — тег, буллеты, цветной блок «Результат». Врезка про пометки дизайнеров + CTA. **Пользователь сам выбирает гайд** (в опросе), мы не «подбираем».
5. **Как это работает** — тёмная секция «8 минут» + 3 шага (шаг 2 = «Выберите свой гайд» — сами) + медовый CTA «Начать опрос».
6. **Автор** — фото Кирилла + био + соцсети (SVG-иконки).
7. **Футер** — вордмарк, blackandhoney.ru, лента выкрасов.

**Картинки:** `img/cover-page-{1,2,3}.png` (обложки гайдов — рендер стр. 1 из `гайд{N}-дизайн`; используются и в телефоне героя, и как мокапы в карточках), `img/kirill-photo.jpg`. Все — из готовых гайдов, единый бренд. Шрифты: Manrope + Unbounded (Prata/засечки НЕ используем — отклонены).
